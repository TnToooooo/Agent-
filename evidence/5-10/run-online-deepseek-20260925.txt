【问题 8】入职一年内、一到两年、两到三年的员工，最近一个月平均工资是多少？
  生成的 SQL：
    WITH latest AS (
      SELECT s.emp_id, s.salary
      FROM salaries s
      WHERE s.pay_date = (SELECT MAX(pay_date) FROM salaries WHERE emp_id = s.emp_id)
    )
    SELECT CASE
             WHEN julianday(date('now')) - julianday(e.hire_date) < 365 THEN '入职一年内'
             WHEN julianday(date('now')) - julianday(e.hire_date) < 730 THEN '一到两年'
             ELSE '两到三年'
           END AS 档位,
           AVG(l.salary) AS 平均工资
    FROM employees e
    JOIN latest l ON e.emp_id = l.emp_id
    WHERE julianday(date('now')) - julianday(e.hire_date) < 1095
    GROUP BY 档位
    ORDER BY MIN(julianday(date('now')) - julianday(e.hire_date));
  查询结果：
    | 入职一年内 | 23964.38 |
    | 一到两年 | 27576.88 |
    | 两到三年 | 29481.88 |
  校验：通过 ✓（结果一致）

【问题 9】去年到今年涨薪幅度最大的10位员工是谁？

           ROUND(AVG(CASE WHEN strftime('%Y', s.pay_date) = strftime('%Y','now') THEN s.salary END)

【问题 10】有没有拖欠工资的情况（某个月还在职却没有发薪）？
  生成的 SQL：
    WITH RECURSIVE em(emp_id, m, end_m) AS (
      SELECT emp_id, strftime('%Y-%m', hire_date),
             COALESCE(strftime('%Y-%m', leave_date), strftime('%Y-%m','now'))
      FROM employees
      UNION ALL
      SELECT emp_id, strftime('%Y-%m', date(m || '-01', '+1 month')), end_m
      FROM em WHERE m < end_m)
    SELECT em.emp_id, em.m FROM em
    LEFT JOIN salaries s ON s.emp_id = em.emp_id AND strftime('%Y-%m', s.pay_date) = em.m
    WHERE s.emp_id IS NULL;
